# Aela Legal Website

This folder is a GitHub Pages-ready static website.

## Before publishing
1. Open `terms/index.html` and `privacy/index.html`.
2. Replace every occurrence of:
   - `[YOUR LEGAL NAME OR BUSINESS NAME]`
   - `[YOUR CONTACT EMAIL]`
   - `[YOUR COUNTRY OR JURISDICTION]`
3. Check that the privacy policy accurately describes the actual Aela build, including any AI, hosting, analytics, or other providers and where data is stored.
4. Do not claim features or security practices that are not implemented.

## Publish with GitHub Pages
1. Create a public GitHub repository named `aela-legal`.
2. Upload the contents of this ZIP (the `index.html`, `terms/`, and `privacy/` paths) to the repository root. Do not upload the outer ZIP folder as an extra nested directory.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to finish deploying.

Your URLs will be:
- Home: `https://YOUR-GITHUB-USERNAME.github.io/aela-legal/`
- Terms: `https://YOUR-GITHUB-USERNAME.github.io/aela-legal/terms/`
- Privacy: `https://YOUR-GITHUB-USERNAME.github.io/aela-legal/privacy/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username. Test both legal URLs in a private/incognito browser window before submitting them to TikTok.

## Important
This is a starter template, not legal advice. Complete all placeholders and make sure the text matches your actual product, business identity, data flows, and applicable law before publishing or submitting it to TikTok.
